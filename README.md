# 🚄 Екатеринбург - Сайт города

Современный веб-сайт города Екатеринбурга с админ-панелью для управления новостями.

## 🌟 Особенности

- 📱 Адаптивный дизайн
- 📰 Система новостей с категориями
- 🔧 Админ-панель для управления контентом
- 📎 Загрузка файлов к новостям
- 🏛️ Страница официальных ссылок
- 🎨 Современный UI/UX дизайн

## 🚀 Деплой на Railway

### Быстрый старт

1. **Подготовка проекта:**
   ```bash
   git clone <your-repo>
   cd <your-project>
   ```

2. **Создание проекта на Railway:**
   - Зайдите на [railway.app](https://railway.app)
   - Создайте новый проект
   - Подключите GitHub репозиторий

3. **Настройка переменных окружения:**
   
   В настройках проекта Railway добавьте следующие переменные:
   
   ```
   SECRET_KEY=your-very-secret-key-here
   FLASK_ENV=production
   FLASK_DEBUG=False
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=your-secure-password
   UPLOAD_FOLDER=static/uploads
   MAX_CONTENT_LENGTH=16777216
   ```

4. **Деплой:**
   - Railway автоматически определит Python проект
   - Установит зависимости из `requirements.txt`
   - Запустит приложение с помощью `gunicorn`

### 📁 Структура проекта

```
├── app.py                 # Основное Flask приложение

```

### 🔧 Настройка

#### Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `SECRET_KEY` | Секретный ключ Flask | `your-secret-key-change-this` |
| `FLASK_ENV` | Окружение Flask | `development` |
| `FLASK_DEBUG` | Режим отладки | `False` |
| `ADMIN_USERNAME` | Логин админа | `admin` |
| `ADMIN_PASSWORD` | Пароль админа | `admin123` |
| `UPLOAD_FOLDER` | Папка загрузок | `static/uploads` |
| `MAX_CONTENT_LENGTH` | Макс. размер файла | `16777216` (16MB) |
| `PORT` | Порт приложения | `8080` (автоматически) |

#### База данных

Приложение использует SQLite базу данных (`news.db`), которая автоматически создается при первом запуске.

#### Файлы

Загруженные файлы сохраняются в папке `static/uploads/` и доступны по URL `/download/<filename>`.

### 🛠️ Локальная разработка

1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Запуск:**
   ```bash
   python app.py
   ```

3. **Доступ:**
   - Сайт: http://localhost:8080
   - Админ-панель: http://localhost:8080/admin/login
