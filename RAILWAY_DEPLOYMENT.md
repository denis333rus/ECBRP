# Railway Deployment Guide

## 🚄 Полная оптимизация для Railway

Ваш проект теперь полностью готов для деплоя на Railway! 

### 📋 Что было добавлено:

#### 1. **requirements.txt** - Зависимости Python
- Flask 2.3.3 - веб-фреймворк
- Werkzeug 2.3.7 - WSGI утилиты
- gunicorn 21.2.0 - WSGI сервер для продакшена
- Все необходимые зависимости с фиксированными версиями

#### 2. **railway.json** - Конфигурация Railway
- Автоматическое определение Python проекта
- Настройка команды запуска с gunicorn
- Healthcheck для мониторинга
- Политика перезапуска при ошибках

#### 3. **Procfile** - Команда запуска
- Использует gunicorn для продакшена
- Автоматически получает порт из переменной PORT
- Привязка к 0.0.0.0 для внешнего доступа

#### 4. **railway.env** - Переменные окружения
- Все необходимые настройки для продакшена
- Безопасные значения по умолчанию
- Инструкции по настройке

#### 5. **.gitignore** - Игнорирование файлов
- Python кэш файлы
- Виртуальные окружения
- Базы данных
- IDE файлы
- Системные файлы

#### 6. **app.py** - Оптимизация для продакшена
- Получение настроек из переменных окружения
- Автоматическое определение порта
- Настройка режима отладки
- Безопасные значения по умолчанию

### 🚀 Инструкция по деплою:

#### Шаг 1: Подготовка репозитория
```bash
git add .
git commit -m "Railway optimization"
git push origin main
```

#### Шаг 2: Создание проекта на Railway
1. Зайдите на [railway.app](https://railway.app)
2. Нажмите "New Project"
3. Выберите "Deploy from GitHub repo"
4. Выберите ваш репозиторий

#### Шаг 3: Настройка переменных окружения
В настройках проекта Railway добавьте:

```
SECRET_KEY=your-very-secret-key-here-change-this
FLASK_ENV=production
FLASK_DEBUG=False
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your-secure-password-here
UPLOAD_FOLDER=static/uploads
MAX_CONTENT_LENGTH=16777216
```

#### Шаг 4: Деплой
Railway автоматически:
- Определит Python проект
- Установит зависимости
- Запустит приложение
- Предоставит URL

### 🔧 Дополнительные настройки:

#### Настройка домена:
1. В настройках проекта Railway
2. Перейдите в "Settings" → "Domains"
3. Добавьте ваш домен

#### Мониторинг:
- Логи доступны в Railway Dashboard
- Healthcheck на `/` endpoint
- Автоматический перезапуск при ошибках

#### Резервное копирование:
- База данных SQLite сохраняется в файловой системе
- Рекомендуется регулярно скачивать `news.db`

### 🛡️ Безопасность:

#### Обязательно измените:
- `SECRET_KEY` - сгенерируйте случайную строку
- `ADMIN_PASSWORD` - используйте сложный пароль
- `ADMIN_USERNAME` - измените логин админа

#### Рекомендации:
- Используйте HTTPS (автоматически на Railway)
- Регулярно обновляйте зависимости
- Мониторьте логи на предмет ошибок

Для обновления приложения:
```bash
git add .
git commit -m "Update"
git push origin main
```

Railway автоматически перезапустит приложение с новыми изменениями.

### 🆘 Решение проблем:

#### Приложение не запускается:
1. Проверьте логи в Railway Dashboard
2. Убедитесь, что все переменные окружения установлены
3. Проверьте синтаксис Python кода

#### Ошибки базы данных:
1. Убедитесь, что папка `static/uploads` создается
2. Проверьте права доступа к файлам
3. Проверьте логи инициализации БД

#### Проблемы с загрузкой файлов:
1. Проверьте переменную `UPLOAD_FOLDER`
2. Убедитесь, что `MAX_CONTENT_LENGTH` установлен
3. Проверьте права доступа к папке uploads
